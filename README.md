--------------------------------------------------------------------------------
  О ПРОЕКТЕ
--------------------------------------------------------------------------------

  Приложение помогает пользователю БЕЗОПАСНО контролировать процесс
  похудения, набора массы или поддержания веса. Рассчитывает
  индивидуальные нормы калорий, БЖУ, воды и клетчатки, ведёт дневник
  питания и тренировок, хранит историю в календаре и формирует отчёты.

  Ключевые возможности:
    [+] Автоматический расчёт дневных норм (калораж, БЖУ, вода, сон)
    [+] Дневник питания и активности по приёмам пищи
    [+] Каталог продуктов: поиск, фильтры, сортировка
    [+] Календарь - архив записей по датам
    [+] Отчёты и аналитика прогресса
    [+] Сохранение данных в бинарные файлы

================================================================================
  1. ВВОДНОЕ ОКНО
================================================================================

  ПРЕДУПРЕЖДЕНИЕ О БЕЗОПАСНОСТИ:
    ! Минимальный срок для снижения веса на 10 кг - 2-3 месяца
    ! Безопасный коэффициент похудения - 0.5-1% массы тела в неделю

  ВВОД ЛИЧНЫХ ДАННЫХ:
    - Никнейм (используется как ID)
    - Возраст
    - Вес
    - Рост
    - Процент жира
    - Цель (желаемый вес)
    - Способ: обычное похудение / сушка / набор массы / поддержание
    - Желаемый срок достижения цели
    - Физические активности из каталога + дни в неделю

  АВТОМАТИЧЕСКИЙ РАСЧЁТ:
    - Примерный дневной калораж
    - БЖУ
    - Норма воды и клетчатки
    - Оптимальные затраты калорий на физ. активность
    - Базовый обмен организма
    - Рекомендуемое количество сна

  После ввода текущей даты в дневнике и календаре автоматически
  создаются пустые записи.

================================================================================
  2. МЕНЮ КОНСОЛИ
================================================================================

  [1] ЛИЧНЫЕ ДАННЫЕ
  --------------------------------------------------------------------------
      - Никнейм - это ID, изменить НЕЛЬЗЯ (поиск по нему)
      - Отображаются рассчитанные нормы
      - Статус пользователя (по умолчанию - "Новичок")


  [2] ДНЕВНИК (питание и физ. активность)
  --------------------------------------------------------------------------
      Разделы:
        - Завтрак
        - Обед
        - Ужин
        - Перекус
        - Вода
        - Физ. активность
        - Сон

      Особенности:
        - Продукты добавляются из каталога или создаются "на лету"
        - БЖУ и калораж считаются автоматически по граммовке
        - В воде и сне отображается норма рядом с введённым значением
        - Для физ. активности учитываются время и интенсивность

      Логика дат:
        - Перед записью вводится текущая дата
        - Если запись есть - открывается на редактирование
        - Если нет - создаётся новая

      [!] Пока нет записей: "Начни отслеживать свои калории!"


  [3] КАТАЛОГ ПРОДУКТОВ
  --------------------------------------------------------------------------
      - Сортировка по алфавиту
      - Поиск по названию
      - Фильтры:
          * по калориям на 100 г
          * по белкам (+-5)
          * по жирам (+-3)
          * по углеводам (+-7)
      - Редактирование
      - Добавление (в т.ч. прямо из дневника)
      - Удаление


  [4] КАЛЕНДАРЬ
  --------------------------------------------------------------------------
      - Хранит все записи по датам
      - Сортировка по дате
      - Поиск по дате
      - Редактирование
      - Удаление


  [5] НОВАЯ ЗАПИСЬ
  --------------------------------------------------------------------------
      Быстрое создание записи на новую дату.


  [6] ОТЧЁТ
  --------------------------------------------------------------------------
      Доступен при наличии МИНИМУМ 10 ДНЕЙ записей:
        - Средний калораж, БЖУ, активность
        - Сравнение с рассчитанными нормами
        - Вывод: придерживается / почти / не придерживается
        - Учёт пропущенных дней


  [7] РЕЗУЛЬТАТ
  --------------------------------------------------------------------------
      Пользователь подтверждает достижение цели:
        - Все данные стираются, КРОМЕ имени
        - Аккаунт создаётся заново с тем же ID

================================================================================
  ДОПОЛНИТЕЛЬНО (опционально)
================================================================================

  Система достижений за регулярность ведения дневника:

      +----------------------+---------------------------+
      |      УСЛОВИЕ         |         СТАТУС            |
      +----------------------+---------------------------+
      |  3 дня подряд        |  "Начало положено"        |
      |  7 дней без пропусков|  "Стальная сила воли"     |
      |  10 дней             |  "Машина"                 |
      +----------------------+---------------------------+

  При получении нового статуса возле пункта "Личные данные"
  появляется [*] (исчезает после просмотра).
